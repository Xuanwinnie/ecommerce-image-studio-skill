# 平台規格與規劃預設值

這些數值是產製階段的安全預設值，不是永久不變的官方規則。正式上架前，應根據商品類別、站點和刊登入口查核當下官方文件，並把來源 URL 與查核日期寫進 `manifest.json`。

## 共通原則

- 保存高解析母版，再從母版輸出各平台版本。
- 主圖避免不必要的裁切、邊框、浮水印與不可驗證宣稱。
- 有文字的圖片要保留安全邊界，並在實際手機縮圖尺寸檢查可讀性。
- 同一套圖片保持商品顏色、Logo、配件、光線方向與品牌色一致。
- 「符合預設檢查」不等於「平台保證通過」。平台政策與類別例外優先。

## 規劃預設值

| 平台／用途 | 建議母版 | 主圖規劃 | 需要特別查核 |
|---|---:|---|---|
| Amazon 商品主圖 | 2000×2000，1:1 | 純白背景、單一實售商品、無促銷文字，商品最長邊目標約占畫面 85% | 類別例外、最低解析度、A+ 模組尺寸 |
| Shopify／獨立站 | 2000×2000，1:1 | 同系列留白、光線與裁切一致；另保留橫幅母版 | 佈景主題的實際容器比例與載入效能 |
| 淘寶／天貓／拼多多 | 800×800 或更高的 1:1 母版 | 第一張優先清楚辨識商品；詳情頁先以 750px 寬規劃 | 各類目主圖文字限制、詳情頁分段規則 |
| 蝦皮 | 1000×1000，1:1 | 縮圖優先，避免過小文字與過度擁擠 | 各國站點差異、促銷標示政策 |
| TikTok Shop | 1080×1080 或 1080×1350 | 商品在手機畫面中清楚，素材可延伸 9:16 | 各市場商品圖片與廣告政策 |
| 小紅書 | 1080×1440，3:4 | 封面標題短、主體清楚、保留 UI 安全區 | 商業內容標示與敏感宣稱 |
| Instagram／Meta Feed | 1080×1350，4:5 | 行動版優先，重要文字置中並留安全區 | 廣告文字、健康／金融等敏感類別政策 |
| Stories／Reels | 1080×1920，9:16 | 上下保留 UI 區域，不把價格或 CTA 貼邊 | 各平台安全區與廣告審核政策 |

## Amazon 主圖檢查預設

`scripts/check_listing_image.py --profile amazon-main` 使用下列保守檢查：

- 接近 1:1。
- 寬高至少 1000px；實務輸出建議 2000px。
- 不含 Alpha 透明通道。
- 邊界接近純白。
- 前景最長邊目標至少占 85%。

背景純度與主體占比是像素估算；透明商品、白色商品、柔和陰影與反射材質可能需要人工覆核。
